
# Credit Card Fraud Detection Using Machine Learning

## Project Overview
This project uses Machine Learning to identify potentially fraudulent credit card transactions. It uses Logistic Regression to classify transactions as legitimate or fraudulent.

## Objectives
- Detect fraudulent credit card transactions.
- Handle the imbalanced nature of the dataset.
- Train and tune a Logistic Regression model.
- Evaluate performance using classification metrics.

## Dataset
The project uses the Credit Card Fraud Detection dataset from Kaggle.

Dataset link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The dataset contains transaction features, including anonymized variables (`V1`–`V28`), transaction time, amount, and a class label.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

## Machine Learning Algorithm
- Logistic Regression
- Class-weight balancing
- GridSearchCV for hyperparameter tuning

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Average Precision
- Confusion Matrix

## How to Run
1. Download or clone this repository.
2. Download the dataset from Kaggle.
3. Install the required Python libraries.
4. Update the dataset path in the notebook.
5. Open the `.ipynb` file in Jupyter Notebook and run the cells.

The model is evaluated using a test dataset and classification metrics. Refer to the notebook for the actual evaluation results.
